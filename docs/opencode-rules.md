# OpenCode 課堂操作規則

與根目錄 AGENTS.md 同時適用。只做環境問答／本機程式練習時，不呼叫 AWS；使用者要求 AWS 實作時才先執行身分與區域核對。

每個關鍵操作說明：目的、完整命令或程式差異、預期結果、影響的資源。先讓學生預測，再由學生核准執行。結果要區分模型建議、工具實際輸出、學生的解釋；看不到證據就寫未測。

不使用 --auto 或永久核准所有 bash 操作。不利用 shell、Python、子程序、符號連結或其他途徑讀出被禁止的秘密。不要讀取或輸出 AWS 憑證、provider auth、DB 密碼、私鑰、簽名 URL、環境變數全集；不能因檔案不在 Git 就假設可傳給模型。AWS CLI 在程式內使用憑證簽章，與把憑證內容送給模型是不同事情。

Big Pickle 是遠端模型，免費期間資料可能用於模型改進；只使用合成測資及可傳給模型的課程程式。免費服務不可用時停下並說明，不自行更改 provider、接入付費模型或建立帳單。主模型及輔助模型都使用 repo 指定模型。

不公開分享會話，不將原始會話／日誌加入 Git；只整理必要且經學生核對的命令、預期、實際、錯誤與回收證據。不得自動填個人理解或將 mock 當成 AWS 實測。permissions 是操作防護，不是隔離沙箱；學生核准腳本前仍須檢查內容。
